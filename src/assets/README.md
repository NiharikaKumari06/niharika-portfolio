# Assets

Replace these with your real files before deploying:

- `profile.jpg` — your professional headshot. Currently the Hero section uses a
  gradient "NK" monogram placeholder instead of an image — once you add
  `profile.jpg` here, import it in `src/components/Hero.jsx` and swap the
  placeholder `<div>` for an `<img src={profile} alt="Niharika Kumari" />`.
- `resume.pdf` — this should go in the `public/` folder (not here), so it can
  be downloaded directly at `/resume.pdf`. A placeholder already exists at
  `public/resume.pdf` — replace it with your real resume.
- `favicon.ico` — an `.svg` favicon is already set up at `public/favicon.svg`.
  Add a `.ico`/`.png` version here and update the `<link rel="icon">` tag in
  `index.html` if you'd prefer a raster favicon.
