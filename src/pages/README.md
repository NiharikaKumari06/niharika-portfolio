# Niharika Kumari - Professional Portfolio

Production-ready, ultra-optimized recruiter-facing developer portfolio built with React, Vite, and Tailwind CSS.

## 🚀 Development Quickstart

Ensure you have [Node.js](https://nodejs.org/) installed on your engine.

```bash
# 1. Clone your generated codebase structural layout
# 2. Ingest structural dependencies
npm install

# 3. Spin up local development server runtime
npm run dev

# 4. Generate highly minified production assets
npm run build
